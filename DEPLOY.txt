No PHP, no server, no build step — and NO SETUP for AI:
  • A built-in NVIDIA key is embedded in js/ai.js, so AI

  • The browser calls NVIDIA's CORS-open NVCF endpoint

    so GitHub Pages needs no relay.
  • Model ids/versions are refreshed from NVIDIA's own
    discovery API at runtime (self-healing), with fallback
    routes: your optional relay → integrate.api.nvidia.com.

 KEY FACTS

   - GPT-OSS 20B — fast (default)

   (saved per device).

   nvidia-relay.js to Cloudflare Workers and paste the URL
   in Settings → AI Connection — it gets tried first.

   speaking — over the same CORS-open NVCF endpoint as
   chat, so no relay is needed. NVIDIA's speech NIMs are
   preview functions; when they don't answer, Live switches
   to your device's own speech engine and labels it in the
   status footer. Neither path records or stores audio, and
   there is NO screen sharing.
 • All data in localStorage on the device. Export/Import
   in Settings → Data.
